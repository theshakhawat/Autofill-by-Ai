# AutoFill by Ai (v1.0) — Chrome Browser Extension

ওয়েব ডেভেলপারদের ফর্ম টেস্টিং সহজ ও দ্রুত করার জন্য তৈরি স্মার্ট AI অটোফিলার এক্সটেনশন। সাধারণ স্ট্যাটিক অটোফিলারের মতো শুধু `input[type]` না দেখে এটি পুরো ফর্মের `<label>`, `placeholder`, `aria-label` এবং আশেপাশের টেক্সট এনালাইসিস করে সঠিক ডাটা বসায়।

## মূল ফিচারসমূহ (V1)
1. **স্মার্ট কনটেক্সট ও ভাষা শনাক্তকরণ (বাংলা ও ইংরেজি)**:
   - লেবেল বা প্লেসহোল্ডারে ইংরেজি থাকলে ইংরেজিতে (যেমন: `Full Name` -> `Abdul Korim`) এবং বাংলায় থাকলে বা বাংলায় লেখার নির্দেশ থাকলে বাংলায় (যেমন: `পূর্ণ নাম (বাংলায়)` -> `আব্দুল করিম`) অটোফিল করে।
   - `First Name` ও `Last Name` আলাদা থাকলে সামঞ্জস্য রেখে প্রথম অংশে `Abdul` এবং শেষ অংশে `Korim` বসায়।
   - ইনপুট টাইপ `number` হলেও যদি লেবেলে `NID নাম্বার` লেখা থাকে, তবে ফোন নাম্বার না দিয়ে সঠিক ১০ বা ১৩ ডিজিটের NID নাম্বার বসায়।
2. **মাল্টি-AI প্ল্যাটফর্ম ও ফ্রি মডেল ডিসকভারি**:
   - **Google Gemini**, **OpenRouter**, **OpenAI**, **Anthropic (Claude)**, **NVIDIA NIM**, এবং **Groq Cloud** সাপোর্ট করে।
   - API Key সেট করার সাথে সাথে ওই প্ল্যাটফর্মের এভেইলেবল ও ফ্রি মডেলগুলো লোড হয় এবং `chrome.storage.local`-এ সেভ থাকে।
3. **১০০% রিলায়েবল Fallback AI সিস্টেম**:
   - প্রাইমারি AI (যেমন Gemini ফ্রি মডেল) কোনো কারণে রেট-লিমিট বা এরর দিলে স্বয়ংক্রিয়ভাবে সেটিংসে সেট করা **Fallback AI** ব্যবহার করে ফর্ম পূরণ সম্পন্ন করে।
4. **ওয়ান-ক্লিক অটোফিল, লোডিং অ্যানিমেশন ও টোস্ট নোটিফিকেশন**:
   - একবার API Key সেভ করার পর যেকোনো ফর্ম পেইজে গিয়ে এক্সটেনশন আইকনে ক্লিক করলেই আইকনে লোডিং অ্যানিমেশন শুরু হবে।
   - ডাটা প্রসেস শেষ হলে আগের লোগো ফিরে আসবে, ব্রাউজারে সাকসেস নোটিফিকেশন দিবে এবং পেইজের নিচে ডান কোণায় (Bottom-Right) একটি প্রিমিয়াম রেড-হোয়াইট টোস্ট মেসেজ দেখাবে।

## ব্রাউজারে ইনস্টল করার নিয়ম (Load Unpacked)
1. প্রথমে `AutoFill-by-Ai-v1.zip` ফাইলটি আনজিপ (Extract) করুন।
2. Google Chrome ব্রাউজারে গিয়ে অ্যাড্রেস বারে লিখুন: `chrome://extensions/` এবং Enter চাপুন।
3. উপরের ডান কোণায় **Developer mode** টগলটি **ON** করুন।
4. বাম পাশের **Load unpacked** বাটনে ক্লিক করে আনজিপ করা ফোল্ডারটি সিলেক্ট করুন।
5. ইনস্টল হওয়ার সাথে সাথে **AutoFill by Ai — Settings** পেইজটি ওপেন হবে। সেখানে আপনার API Key ও মডেল সেভ করে ডান পাশের **Live Developer Sandbox** ফর্মে সাথে সাথে টেস্ট করতে পারবেন!
