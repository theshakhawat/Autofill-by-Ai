Privacy Policy for AutoFill by Ai

Last Updated: November 2026

AutoFill by Ai is dedicated to protecting user privacy. This privacy policy explains our handling of user data and credentials.

1. Information We Process:
AutoFill by Ai temporarily reads form labels, placeholders, input types, and ARIA attributes from the webpage where the user initiates an autofill action. This data is used solely to generate relevant test values for those specific fields.

2. API Keys and Credentials:
All API keys entered by the user are stored locally in the browser's chrome.storage.local container. API keys are sent directly to the official API endpoints of the user-selected AI providers (such as Google, OpenAI, Anthropic, Groq, OpenRouter, etc.). The developer does not operate any intermediate proxy or server, and cannot access or view your API keys.

3. Data Collection and Tracking:
- We do not collect, store, sell, or transfer any personal data.
- We do not use analytics trackers, telemetry scripts, or cookies.
- No form data or generated mock values are stored after the autofill process completes.

4. Contact:
If you have any questions regarding this privacy policy, please open an issue in the official project repository.
