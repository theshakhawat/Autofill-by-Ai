STEP 01 • PRIMARY ENGINE

প্রাইমারি AI প্ল্যাটফর্ম ও API Key

আপনার পছন্দের AI কোম্পানি সিলেক্ট করে API Key দিন। একবার সেভ করলে পরবর্তীতে এক্সটেনশন আইকনে ক্লিক করলেই সরাসরি ফর্ম অটোফিল হবে।

লোকাল ব্রাউজার স্টোরেজে (`chrome.storage.local`) সংরক্ষিত থাকবে। API Key দেওয়ার সাথে সাথে এভেইলেবল ও ফ্রি মডেলগুলো নিচে লোড হবে।

HOW IT WORKS

কিভাবে ব্যবহার করবেন?

  • ১. ওয়ান-টাইম সেটআপ: আপনার পছন্দের AI প্ল্যাটফর্ম ও API Key দিয়ে মডেল সিলেক্ট করে সেভ করুন।
  • ২. ওয়ান-ক্লিক অটোফিল: যেকোনো রেজিস্ট্রেশন বা ফর্ম পেইজে গিয়ে ব্রাউজারের এক্সটেনশন আইকনে ক্লিক করুন—আইকনে লোডিং অ্যানিমেশন দেখাবে এবং ব্যাকগ্রাউন্ডে ফর্ম এনালাইসিস হবে।
  • ৩. সেটিংস আপডেট: যেকোনো সময় API Key বা মডেল পরিবর্তন করতে এক্সটেনশন আইকনে রাইট-ক্লিক করে "Options" বা "⚙️ AutoFill by Ai — Settings"-এ যান।
